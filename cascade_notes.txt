Cascade: a claim stands only while everything beneath it stands. Agents pass findings to each other; when a source is revoked, the finding is wrong everywhere it travelled. A fact is a statement plus the one public source that backs it, and anyone can ask a GenLayer round to read that source now: SUPPORTED, the fact stands; UNSUPPORTED (contradicted, revoked, expired or never recorded), it falls. Derived claims are built on earlier claims and stand only while every parent stands, so one revoked source knocks down everything built on it, and why(id) names the fact that fell. Falling is permanent: a fact cannot be re-checked back up, a restored source is a new fact. The source is untrusted data: a page that only orders SUPPORTED backs nothing, and a record that backs the fact is not overruled by a note ordering UNSUPPORTED, both proven on chain, along with a real revocation bringing a chain down. Contracts gate on stands(id).
